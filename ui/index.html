Red

Aplica desde la próxima reproducción. Si el firewall o el router lo bloquean, todo sigue funcionando solo con conexiones salientes.

Para recibir conexiones entrantes (más peers; suele bajar más rápido):

  1. Probá con UPnP: dejá activadas las dos opciones de arriba y verificá. Si el router lo soporta, abre el puerto solo. Algunos lo rechazan (por ejemplo, los Sagemcom de los cable-módems).
  2. Si da cerrado, abrí el puerto a mano: entrá al router (suele ser 192.168.0.1 o 192.168.1.1), buscá "Reenvío de puertos", "Port forwarding" o "NAT" y creá una regla: protocolo TCP, puerto externo e interno 41850, hacia la IP de esta PC (la muestra "Verificar"). Conviene reservar esa IP en el DHCP del router para que no cambie.
  3. Firewall: en macOS, Ajustes del Sistema › Red › Firewall › Opciones: permití las conexiones entrantes de Streamonte. En Windows, aceptá el aviso del firewall la primera vez.
  4. Si aun así da cerrado: tu proveedor puede usar CGNAT (sin IP pública propia). Pedile una IP pública; sin eso no se pueden recibir entrantes.

"Verificar" abre el puerto un momento y le pide a portchecker.io que intente conectarse a tu IP pública (que averigua con api.ipify.org).
